# 杭州电子科技大学 · 近代史纲要刷题网页

杭州电子科技大学「中国近现代史纲要」课程刷题网页，打开即用，无需安装。

🔗 **在线使用**：<https://phoenix-chenli.github.io/jindaishi-quiz/>

## 简介

这是一个面向杭州电子科技大学「中国近现代史纲要」课程的在线刷题网页，题库收录 483 道单项选择题，覆盖课程各章节要点。页面为纯前端单文件实现，手机、平板、电脑浏览器都能直接打开，答题进度自动保存在本地。

## 功能

| 模式 | 说明 |
| :-- | :-- |
| 📝 顺序练习 | 按题库顺序逐题作答，适合完整地过一遍知识点 |
| 🎲 随机练习 | 打乱题目顺序随机出题，避免形成位置记忆 |
| 🔁 错题回顾 | 自动收录答错的题目，答对后移出错题本 |
| 📋 模拟自测 | 从题库随机抽取 50 题，每题 2 分，满分 100 分，结束给出得分与正确率 |

其他细节：

- 作答后即时判对错，并高亮显示正确答案
- 顶栏实时显示进度（0/483）、正确数、错误数、正确率
- 题号导航面板可跳转到任意题目
- 答题记录与自测进度保存在浏览器 `localStorage`，刷新页面不丢失
- 版本更新时自动清理旧缓存数据，避免新旧题库混用
- 移动端适配，方便单手操作

## 使用方法

在线版直接访问 <https://phoenix-chenli.github.io/jindaishi-quiz/>。

本地使用可以先克隆仓库，再双击 `index.html`，或用任意静态服务器打开：

```bash
git clone https://github.com/phoenix-chenli/jindaishi-quiz.git
cd jindaishi-quiz
# 直接双击 index.html 即可开始刷题
```

## 技术说明

- 纯 HTML + CSS + JavaScript，无框架、无构建流程、无第三方依赖
- 题库以 JSON 数组形式内嵌于页面
- 练习进度存储使用 `localStorage`
- 通过 GitHub Pages 部署
